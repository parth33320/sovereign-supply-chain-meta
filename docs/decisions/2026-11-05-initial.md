# Decision Log — 2026-11-05 — Initial Architectural Foundation

## Session Type
[x] Feature  [ ] Bug fix  [x] Refactor  [x] Docs  [x] Security

## What was built or changed
- Removed Celery asynchronous worker in favor of synchronous LangGraph execution for reliable, deterministic orchestration
- Enabled DEMO_MODE as standard fallback for deployments without external workers or PostgreSQL instances
- Kept flat project folder structure intentionally to minimize import depth and simplify multi-agent execution
- Removed Portfolio dashboard from UI navigation rail to focus strictly on operational core modules
- Removed Chaos testing controls from user-facing UI and preserved in automated test suite
- Removed tenant dropdown selector and hardcoded Tenant_A for tenant isolation clarity
- Updated voice transcription endpoint from OpenAI SDK to direct POST /v1/asr/transcribe via requests.post with mode: PUSH_TO_TALK
- Adopted render_with_error_boundary() UI pattern to prevent unhandled tracebacks reaching operators
- Adopted @with_rate_limit_retry decorator pattern in api_resilience.py for all Meta API calls

## Why (the problem being solved)
- Streamline user interface for warehouse operators, remove dev/chaos bloat, enforce resilience across Meta AI endpoints, and provide a self-contained runtime under single-command deployment.

## Alternatives considered and rejected
| Option | Reason rejected |
|--------|----------------|
| Asynchronous Celery + Redis workers | Added unnecessary deployment failure points for interactive Streamlit workflows |
| Dynamic multi-tenant dropdown switcher | Cluttered header and posed potential cross-tenant leakage risks in demo mode |
| OpenAI SDK wrapper for audio transcription | Caused schema mismatch; Meta ASR requires raw bytes POST to /v1/asr/transcribe |
