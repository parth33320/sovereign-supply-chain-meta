# VR Fixes Plan: 4 Critical Fixes

## Overview

Four independent fixes for the Supply Chain XR Walk VR experience:

1. **Fix 1** — A2A log panel x-offset (prevents overlapping PO card)
2. **Fix 2** — Cursor dot on HUD buttons (Voice/Reset buttons in hdrPanel)
3. **Fix 3** — XR tooltip on mic gaze (HUD shows voice hints when gazing at mic button)
4. **Fix 4** — AR → XR text rename (all UI-visible strings)

---

## Current State Analysis

### Fix 1: A2A Log Position
- **Location**: `frontend/vr/index.html` line 949
- **Current**: `logMesh.position.set(-0.55, 0, 0.01)`
- **Issue**: PO card is 0.78m wide (PlaneGeometry 0.78), half-width = 0.39m. Log panel at -0.55m overlaps by ~0.16m
- **Fix**: Push to -0.72m (clears PO card half-width + log panel half-width = 0.39 + 0.25 = 0.64m, with margin)

### Fix 2: Cursor Dot on HUD Buttons
- **Location**: `frontend/vr/index.html` lines 746-749
- **Current**: Targets array checks `spatialCardGroup` first, then all `shelfGroup.children`
- **Issue**: Raycast hits shelf geometry (planks, pillars) before HUD buttons. Buttons are in `hdrPanel` → `shelfGroup.children` but depth-sorted behind shelf meshes
- **Fix**: Add `btn3DMic`, `btn3DReset` to targets FIRST (priority over shelf geometry)

### Fix 3: XR Tooltip on Mic Gaze
- **Location**: `frontend/vr/index.html` lines 740-754 (cursor dot block) + state vars near line 193
- **Current**: No gaze tracking for HUD updates
- **Fix**: Add `_prevHudHover` state var, check if hit object is `btn3DMic`, update HUD with `getVoiceTooltip()` on gaze enter/exit

### Fix 4: AR → XR Text Rename
- **Location**: Multiple lines in HTML and JS strings (UI-visible only)
- **Do NOT rename**: CSS IDs (#ar-scene, #ar-panel), JS functions (startARSession), JS variables (xrSession, xr-active class), WebXR API strings

```javascript
// FIND (lines 740-754):
    // Update pointer ray & cursor dot from primary active controller/hand
    cursorDot.visible = false;
    const activeCtrl = xrControllers.find(c => c.visible) || xrControllers[0];
    if (activeCtrl) {
      const { origin, dir } = getControllerRay(activeCtrl);
      raycaster.set(origin, dir);
      {
        const targets = [];
        if (spatialCardGroup.visible) targets.push(cardBtnPrimary, cardBtnSecondary);

          cursorDot.visible = true;

        }
      }
    }

// REPLACE:
    // Update pointer ray & cursor dot from primary active controller/hand
    cursorDot.visible = false;
    const activeCtrl = xrControllers.find(c => c.visible) || xrControllers[0];
    if (activeCtrl) {
      const { origin, dir } = getControllerRay(activeCtrl);
      raycaster.set(origin, dir);
      {
        const targets = [];
        // HUD buttons first (priority over shelf geometry)
        if (shelfGroup.visible) targets.push(btn3DMic, btn3DReset);
        if (spatialCardGroup.visible) targets.push(cardBtnPrimary, cardBtnSecondary);
        if (shelfGroup.visible) targets.push(...shelfGroup.children);
        const hits = raycaster.intersectObjects(targets, true);
        if (hits.length > 0) {
          cursorDot.visible = true;
          cursorDot.position.copy(hits[0].point);
          // Show voice tooltip in HUD when gazing at mic button
          const gazingAtMic = hits[0].object === btn3DMic;
          if (gazingAtMic && !_prevHudHover) {
            update3DHudStatus(getVoiceTooltip());
            _prevHudHover = true;
          } else if (!gazingAtMic && _prevHudHover) {
            update3DHudStatus("Supply Chain XR · Ready");
            _prevHudHover = false;
          }

          update3DHudStatus("Supply Chain XR · Ready");
          _prevHudHover = false;
        }
      }
    }
```

- **Fix 1**: Conservative -0.72m offset; can adjust if too far

- **Fix 3**: `_prevHudHover` prevents HUD flicker; fallback to default status when cursor leaves all targets
- **Fix 4**: Strictly UI strings only; technical identifiers preserved to avoid breaking WebXR session logic
