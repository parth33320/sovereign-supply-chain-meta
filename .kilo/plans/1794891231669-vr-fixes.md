## Fix 2 — Fix onXRSelect Early-Return During Auto-Place

**Find** (lines 556-571):
```javascript
  function onXRSelect(event) {
    const ctrl = event.target;
    if (!shelfPlaced) {
      if (reticle.visible) {
        shelfGroup.position.setFromMatrixPosition(reticle.matrix);
        shelfGroup.position.y = 0; // Exact Guardian floor level (y = 0)
        const camPos = new THREE.Vector3();
        camera.getWorldPosition(camPos);
        shelfGroup.lookAt(camPos.x, 0, camPos.z);
        shelfGroup.visible = true;
        shelfPlaced = true;
        reticle.visible = false;
        setStatus("Shelf anchored on floor · Pinch or touch Widget-A");
      }
      return;
    }
```

**Replace with**:
```javascript
  function onXRSelect(event) {
    const ctrl = event.target;
    if (!shelfPlaced) {
      if (reticle.visible) {
        shelfGroup.position.setFromMatrixPosition(reticle.matrix);
        shelfGroup.position.y = 0;
        const camPos = new THREE.Vector3();
        camera.getWorldPosition(camPos);
        shelfGroup.lookAt(camPos.x, 0, camPos.z);
        shelfGroup.visible = true;
        shelfPlaced = true;
        reticle.visible = false;
        setStatus("Shelf anchored on floor · Pinch or touch Widget-A");
        return;
      }
      // Auto-place mode: no reticle — fall through to shelf interaction if shelf is visible
      if (!shelfGroup.visible) return;
    }
```

**Rationale**: With the 60-frame auto-place delay (Change 4b), `shelfGroup.visible` becomes `true` at line 668 (`autoPlaceShelf()`) before `shelfPlaced` becomes `true` (line 658). During those ~60 frames, a pinch would hit the early `return` at line 570 and do nothing — blocking Widget-A taps. The fix: when `reticle` is not visible (auto-place mode) but shelf IS visible, fall through to the shelf interaction code below instead of returning early.
